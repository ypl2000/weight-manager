# Tailscale 出门访问指南

> 适用：人在外面（手机流量、公司网络、外地）也想打开家里的体重管理应用。
> 方案选型：Tailscale 免费档（个人 3 用户 / 100 设备）、全程 WireGuard 加密、不把应用暴露到公网、无需改路由器。

## 原理一句话

给电脑和手机各装一个 Tailscale 客户端，登录同一账号后，它们会获得一个固定的虚拟 IP（`100.x.x.x`），之后无论手机用流量还是公司 WiFi，都能直连家里的电脑——就像随身带着一根看不见的家庭网线。

## 第一步：电脑端（服务所在机器）

1. 安装：`winget install Tailscale.Tailscale`，或到 https://tailscale.com/download 下载 Windows 版
2. 安装后右下角托盘出现图标 → 点击 **Log in** → 浏览器里注册/登录（支持 Google / Microsoft / GitHub / Apple / 邮箱验证码）
3. 登录后获取电脑的 Tailscale IP：按 `Win+R` → `cmd` → 输入 `tailscale ip -4`，记下形如 `100.101.102.103` 的地址
4. 确认应用服务在跑（start.bat 或开机自启任务已启动，浏览器能打开 http://127.0.0.1:8000）

## 第二步：手机端

1. 应用商店安装 Tailscale（iOS App Store / Android 各应用商店或 Google Play）
2. 登录**同一个**账号
3. 打开 Tailscale 开关，等它显示 Connected

## 第三步：在手机上使用

1. 手机浏览器（无论 WiFi 还是流量）访问 `http://100.101.102.103:8000`（换成你第一步记下的 IP）
2. 能打开后，建议**重新"添加到主屏幕"**一次（或直接改用这个地址），从此在家在外都是它
3. 原来的局域网地址 `192.168.x.x:8000` 在家里依然可用，两者不冲突

## 第四步：安全与防火墙（建议都做）

1. **开启访问码**：应用 → 设置 → 数据安全 → 设置访问码。出门访问等于把服务扩到了外网通道，虽然有 Tailscale 加密，再加一层访问码更稳妥
2. **Windows 防火墙**：如果手机连不上但电脑本机正常，大概率是防火墙拦了 Tailscale 网卡的 8000 端口。管理员 PowerShell 执行一次即可（对所有网卡放行 8000 入站）：
   ```powershell
   New-NetFirewallRule -DisplayName "WeightManager 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
   ```

## 常见问题

- **国内登录 Tailscale 卡住？** 注册/登录页走的是国际服务，偶尔需要耐心或换个时段；登录成功后的日常连接一般没问题（优先直连，慢时走官方中继）
- **速度慢？** Tailscale 会优先尝试设备间直连（打洞），成功后速度就是你家宽带上行速度；只有打洞失败才走中继
- **免费档限制？** 个人版 3 个用户 / 100 台设备，家庭自用绰绰有余
- **想撤销？** 电脑端托盘退出并卸载、手机端删除 App 即可，应用本体和数据完全不受影响；如果之前改了主屏地址，改回局域网地址即可

## 与本应用的关系

应用的离线优先设计天然适配出门访问：断网/连不上时照常本地记录，Tailscale 连上（或回家连 WiFi）后自动双向同步。出门访问只是"让同步更及时"，不改变任何数据逻辑。
