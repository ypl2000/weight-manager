# 体重管理(自部署版)

电脑端部署、手机当 APP 用的体重管理应用。数据存在自己电脑里,不出家门。

> **首次体验说明**:数据库里预置了几条示例数据(体重 89.4→88.5、腰围 96、体脂率),用于展示图表和阶段判定效果。在"数据 → 录入"页的最近记录里点"删"即可清掉,换成自己的真实数据。

- **记录**:体重、腰围、臀围、腰臀比、体脂率、餐后血糖……指标可自定义
- **阶段判定**:按白板方案《苹果型运动》预置三阶段(①降糖稳食欲降腰围 → ②过渡期有氧:力量=1:1 → ③增肌塑形力量为主),按最近数据自动建议,依据逐条可查;规则、模板、指标、清单全部可在界面增删改
- **每日打卡**:控糖抗炎饮食、7-8小时睡眠、4-7-8呼吸等习惯清单(来自《内脏脂肪》白板)
- **拍照识别**:拍体重秤/体脂秤截图,AI 提取数值,确认后入库(手机、电脑都能用)
- **批量导入**:苹果健康 export.zip、华为运动健康数据副本、通用 CSV 三种来源,自动识别列名与日期格式、斤/lb 换算、体脂率小数/百分比双口径;重复导入自动去重(设置 → 批量导入历史数据)
- **AI 教练**:基于近 7/30/90 天的记录与打卡数据生成趋势解读和下周建议(今日页入口),解读遵循"热量缺口底座、蛋白质 1.2-1.6g/kg、看长期趋势、真假平台期诊断"等知识库原则,流式输出、自动存档可回看
- **离线优先**:手机本地存一份数据,断网可正常记录;联网后按"更新时间新者胜"与电脑自动同步
- **历史与回滚**:每次改动都留版本,可单条恢复;每天自动全量快照,可整体回滚/导出

## 一、启动(电脑端)

双击 `start.bat`(首次运行会自动创建 Python 虚拟环境并装依赖),看到

```
INFO:     Uvicorn running on http://0.0.0.0:8000
```

即启动成功。浏览器访问 http://127.0.0.1:8000 就是电脑端界面。

> 前端已预构建在 `frontend/dist`。如果改了前端代码,重新构建:
> ```
> cd frontend && npm install && npm run build
> ```

## 二、手机端(第一次配置)

1. 手机和电脑连**同一个 WiFi**
2. 电脑上按 `Win+R` 输入 `cmd` 回车,再输 `ipconfig`,找到"IPv4 地址",例如 `192.168.1.100`
3. 手机浏览器打开 `http://192.168.1.100:8000`
4. 手机浏览器菜单 → **添加到主屏幕 / 添加到桌面**,之后从图标进入即全屏 APP 体验
5. 若打不开:检查 Windows 防火墙是否放行了 Python/8000 端口(第一次启动时的弹窗选"允许")

> 首次启动 Windows 防火墙弹窗请选择"允许访问"。

## 三、拍照识别配置

默认是**演示模式**(返回演示数据,用于体验流程)。要真实识别:

1. 到 [智谱开放平台](https://open.bigmodel.cn) 注册并创建 API Key(任何兼容 OpenAI vision 接口的服务都行)
2. 应用里 设置 → AI识别 → 填 Key,关闭"演示模式" → 保存
3. 数据页 → 📷 识别 → 拍照/选图 → 识别 → 确认结果入库

## 四、数据安全

- **访问码**:设置 → 数据安全 → 设置访问码后,所有设备需输入一次(存在本机)
- **历史回滚**:设置 → 数据安全 → 查看最近历史 → 恢复此版本
- **每日快照**:服务端每天首次启动自动备份到 `backend/data/backups/`,保留30份,可下载/整体恢复
- **导出**:全部数据 JSON / 记录 CSV,随时带走

## 五、数据互通原理

界面读写都走手机本地(IndexedDB),秒开、断网可用;后台自动把本地变更推给服务端、拉回其他设备的变更,按每条记录的 `updated_at` **新者覆盖旧者**,删除用软删除防止丢失。单人多设备场景足够可靠。

## 六、目录结构

```
backend/    Python FastAPI + SQLite
            main.py 路由 / store.py 存储(同步+历史) / engine.py 阶段判定
            recognize.py 拍照识别 / importers.py 数据导入 / coach.py AI教练
frontend/   Vue3 + Vite + ECharts PWA(dist 为构建产物)
docs/       调研报告与知识资料
qa/         测试清单、报告、审计与缺陷台账
start.bat   一键启动
```
