# 体重管理（自部署版）

电脑端部署、手机当 APP 用的体重管理应用。数据存在自己电脑里，不出家门。开源仓库可直接克隆部署。

> **首次体验说明**：数据库预置了几条示例数据（体重 89.4→88.5、腰围 96、体脂率），用于展示图表和阶段判定效果。在"数据 → 录入"页的最近记录里点"删"即可清掉，换成自己的真实数据。

## 功能一览

- **记录**：体重、腰围、臀围、腰臀比、体脂率、餐后血糖……指标可自定义
- **阶段判定**：预置三阶段（①降糖稳食欲降腰围 → ②过渡期有氧:力量=1:1 → ③增肌塑形力量为主），按最近数据自动建议，依据逐条可查；规则、模板、指标、清单全部可在界面增删改
- **每日打卡**：控糖抗炎饮食、7-8小时睡眠、4-7-8呼吸等习惯清单
- **拍照识别**：拍体重秤/体脂秤截图，AI 提取数值，确认后入库（双端可用）
- **批量导入**：苹果健康 export.zip、华为运动健康数据副本、通用 CSV，自动识别列名与日期，重复导入自动去重
- **AI 教练**：周报 + "问教练"自由问答——回答优先引用知识库并注明出处，知识库未覆盖才用通用知识并标注；知识库内容在 `docs/知识汇总-整理版.md`，可自行扩充
- **智能提示**：减重速率超 1kg/周 警告、真假平台期检测、按体重和阶段的每日蛋白质目标
- **测量提醒**：体重每天、腰围每周，横幅提示 + 桌面通知
- **离线优先**：手机本地存一份数据，断网可记录；联网自动双向同步
- **历史与回滚**：每次改动留版本，可单条恢复；每日自动快照，可整体回滚/导出

## 一、电脑端部署（服务端，必做）

**要求**：Windows + Python 3.10+（开发环境 3.13 验证）；手机端不需要装任何东西。

1. 克隆或下载本仓库到电脑（建议放在不含特殊字符的路径）
2. 双击 **`start.bat`** —— 首次运行会自动创建 Python 虚拟环境并安装依赖
3. 看到 `Uvicorn running on http://0.0.0.0:8000` 即成功，电脑浏览器访问 http://127.0.0.1:8000
4. 首次启动时 Windows 防火墙弹窗选择 **"允许访问"**（手机访问依赖它）；如果当时点了拒绝，管理员 PowerShell 执行：
   ```powershell
   New-NetFirewallRule -DisplayName "WeightManager 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
   ```
5. **（可选）开机自启**：双击 `scripts/autostart-install.bat`（免管理员），以后开机服务自动在后台运行；卸载跑 `scripts/autostart-uninstall.bat`
6. **（可选）AI 功能 Key**：到 [智谱开放平台](https://open.bigmodel.cn) 申请 API Key，应用"设置 → AI 识别"里填入——拍照识别和 AI 教练即变真实调用（不填也能用演示模式体验流程）

> 修改了前端代码才需要重新构建：`cd frontend && npm install && npm run build`

## 二、手机端部署（客户端，两种方式）

### 方式 A：家里 WiFi 使用（最常用，5 分钟）

1. 手机和电脑连**同一个 WiFi**
2. 电脑上查 IP：`Win+R` → `cmd` → `ipconfig`，找"IPv4 地址"（形如 `192.168.x.x`，以实际为准；本机当前为 `7.250.215.168`）
3. 手机浏览器打开 `http://那串IP:8000`
4. 浏览器菜单 → **添加到主屏幕 / 添加到桌面**——之后从图标进入，全屏运行和 APP 一样
5. 打不开 → 九成是防火墙（见上文第 4 步）或手机用了流量

数据存在手机本地（断网可照常记录），回家连上 WiFi 自动与电脑双向同步。

### 方式 B：出门也能用（Tailscale，可选）

按 [docs/tailscale-guide.md](docs/tailscale-guide.md) 操作：电脑和手机各装一个 Tailscale（免费）、登录同一账号，手机改用电脑的 Tailscale 地址（`100.x.x.x:8000`）即可——4G/5G、外地、公司网络都能用，全程加密不暴露公网。配好后建议在"设置 → 数据安全"开启访问码。

## 三、拍照识别配置（可选）

默认演示模式（返回演示数据，用于体验流程）。真实识别：智谱开放平台申请 Key → "设置 → AI 识别"填入并关闭演示模式。兼容任何 OpenAI vision 接口格式的服务商。

## 四、数据安全

- **访问码**：设置 → 数据安全，开启后所有设备输入一次即可（存在本机）
- **历史回滚**：每次增删改都留版本，可单条恢复；每天自动全量快照（保留 30 份），可整体恢复
- **导出**：全部数据 JSON / 记录 CSV，随时带走
- **隐私**：数据库（`backend/data/`）不入版本库，开源仓库不含任何用户数据

## 五、数据互通原理

界面读写走本地（电脑=SQLite，手机=IndexedDB），秒开、断网可用；后台自动双向同步，按每条记录的 `updated_at` 新者覆盖，删除用软删除防丢失。单人多设备场景足够可靠。

## 六、目录结构

```
backend/    Python FastAPI + SQLite
            main.py 路由 / store.py 存储(同步+历史) / engine.py 阶段判定
            recognize.py 拍照识别 / importers.py 数据导入 / coach.py AI教练
            insights.py 智能提示 / reminders.py 测量提醒
frontend/   Vue3 + Vite + ECharts PWA（dist 为构建产物）
docs/       调研报告 / Tailscale 指南 / 知识库素材
qa/         测试清单、报告、审计与缺陷台账
scripts/    开机自启安装/卸载
start.bat   电脑端一键启动
```

## 七、接口约定

`/api/coach/report` 与 `/api/coach/ask` 为 SSE 流式接口：HTTP 状态恒为 200，错误通过流内 `data: {"error": "..."}` 事件返回（参数校验失败不消耗模型调用）。
